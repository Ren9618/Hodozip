Features

  • Extract immediately by double-clicking

    Double-click a supported archive such as .zip, .7z, .rar, or .msi and extraction starts right away. The familiar feel of classic extraction tools, brought to modern Windows 11.

  • Japanese / English UI

    Choose Follow system settings / Japanese / English in Settings. Language changes take effect the next time Hodozip starts.

  • Faster ZIP extraction with parallelism

    ZIP entries are extracted in parallel. In our large-archive benchmark, extraction dropped from 5,336 ms sequential to 806 ms parallel, about 6.6x faster (results vary by environment).

  • Automatic destination selection

    Hodozip chooses where to extract based on the archive contents. Archives that contain a single top-level folder are not wrapped in a duplicate folder.

  • Japanese filename encoding support

    File names inside ZIP archives are detected as UTF-8 or Shift_JIS and extracted without garbled Japanese characters.

  • Password-protected ZIP support

    ZipCrypto and AES password-protected ZIP archives are supported. Hodozip asks for the password inside the app when it needs one.

  • Windows 11 context menu support

    Right-click a supported archive and choose "Extract with Hodozip" or "Extract to folder with Hodozip" (MSIX build).

  • No network, telemetry, or ads

    The app does not communicate over the network and contains no telemetry or advertising. It is published as MIT-licensed open source.

Supported formats: ZIP / 7z / RAR / MSI / TAR / GZ / BZ2 / XZ / ZST. The UI is available in Japanese and English.

How to use

1. Install and launch

zip build (no installation)

  1. Extract the downloaded zip file.
  2. Launch Hodozip.exe inside it.
  3. Drag an archive into the window or choose one with "Select file". Progress is shown while extracting, and "Open folder" opens the destination when it finishes.

MSIX build (experimental)

Install the certificate first, then the package. For detailed steps and uninstallation, see "MSIX installation" in the README.

  1. Download the public certificate Hodozip-Test.cer.
  2. Register the certificate in an elevated PowerShell window.
certutil -addstore -f TrustedPeople .\Hodozip-Test.cer
  1. Download Hodozip-0.4.0.msix from GitHub Releases and install it.
Add-AppxPackage -Path .\Hodozip-0.4.0.msix

To extract by double-clicking, configure Hodozip as the default app as described in the next section.

2. Set Hodozip as the default app for supported archives (extract by double-click)

Windows does not let apps force file associations. Follow these steps to make Hodozip the default for .zip and other supported extensions.

  1. Open Windows Settings → Apps → Default apps.
  2. Search for zip and select ".zip".
  3. Choose "Hodozip" from the list.

Alternatively, right-click a .zip file → "Open with" → "Choose another app" → "Hodozip" → "Always use this app". The MSIX build registers itself as an association candidate.

3. Extract from the context menu (MSIX / Windows 11)

Right-click a supported archive and choose one of the following. The menu labels follow the OS display language.

  • Extract with Hodozip — chooses the destination automatically based on the archive contents.
  • Extract to folder with Hodozip — always creates a folder named after the archive and extracts into it.

If the entry does not appear in the new Windows 11 context menu, choose "Show more options" (or press Shift + F10). Restarting Explorer after installation can also help. This menu targets Windows 11 and may not appear on Windows 10.
