Windows 向け・無料・オープンソースのアーカイブ解凍・圧縮ソフト

Hodozip

アーカイブを、ほどく。

ダブルクリックで、その場に、文字化けなしで解凍。
アーカイブをドラッグ＆ドロップしても、そのまま解凍できます。ZIP / 7z の圧縮にも対応しました。

ダウンロード GitHub リポジトリを見る
  • 現在のバージョン v0.5.0
  • Windows 10（19041 以降）/ Windows 11
  • MIT ライセンス

特徴

  • ダブルクリックですぐ解凍

    .zip や .7z、.rar、.msi などの対応アーカイブをダブルクリックすると、その場ですぐに解凍が始まります。往年の解凍ソフトの使い勝手を、現代の Windows 11 に引き継ぎました。

  • ZIP / 7z の圧縮にも対応

    ZIP / 7z の作成に対応しました。圧縮レベル（保存 / 標準 / 最高）、ZIP の AES パスワード、ZIP のファイル名エンコーディング（UTF-8 / Shift_JIS）を選べます。右クリックメニューやドラッグ＆ドロップからも圧縮を開始できます。

  • 日本語 / English UI

    設定画面の「言語」で、システム設定に従う / 日本語 / English を選べます。言語の変更は次回起動時に反映されます。

  • ZIP の並列解凍で高速化

    ZIP をエントリ単位で並列に解凍します。大容量 ZIP の計測では逐次 5,336 ms から並列 806 ms へ、約 6.6 倍高速になりました（環境により変動します）。

  • 解凍先フォルダの自動判定

    アーカイブの内容に応じて展開先を自動で判定します。単一フォルダ型のアーカイブは二重フォルダにせず、後片付けがしやすい形のまま展開します。

  • 日本語ファイル名の文字化け対策

    ZIP 内のファイル名を UTF-8 / Shift_JIS で自動判別し、日本語のファイル名を文字化けさせずに展開します。

  • パスワード付き ZIP 対応

    ZipCrypto / AES のパスワード付き ZIP に対応しています。暗号化された ZIP を展開するときは、アプリ内でパスワードを入力します。

  • 右クリックメニュー対応

    対応アーカイブを右クリックして「Hodozip で解凍」「Hodozip でフォルダに解凍」、ファイルを右クリックして「Hodozip で圧縮」が選べます（MSIX 版は Windows 11 の新しいメニュー、インストーラー版は従来型メニュー）。

  • 通信は更新確認のみ

    通常の解凍・圧縮はネットワーク通信を行いません。自動アップデートの確認時のみ GitHub Releases にアクセスし、設定画面で OFF にできます。テレメトリも広告もありません。

対応形式（解凍）は ZIP / 7z / RAR / MSI / TAR / GZ / BZ2 / XZ / ZST 系です。作成は ZIP / 7z に対応しています。UI は日本語 / English に対応しています。

スクリーンショット

アプリの画面写真は、あとでここに掲載します。

ダウンロード

最新版は GitHub Releases から入手できます。配布形式は 3 種類あります。

インストーラー版

推奨

Hodozip-0.5.0-setup.exe

  • 管理者権限不要で、ユーザーごとに %LOCALAPPDATA%\Programs\Hodozip へインストールします
  • スタートメニューのショートカットを作成し、任意で右クリックメニューと「プログラムから開く」への登録を行います
  • アンインストールは Windows の「設定」→「アプリ」から行えます
Release から入手

zip 版

ポータブル

Hodozip-0.5.0-win-x64.zip

  • 解凍して Hodozip.exe を起動するだけで使えます（インストール不要）
  • アーカイブのドラッグ＆ドロップやパス指定で解凍
Release から入手

MSIX 版

実験的な配布

Hodozip-0.5.0.msix

  • 対応アーカイブのファイル関連付け候補と Windows 11 の右クリックメニューが登録されます
  • インストール前に自己署名証明書の登録が必要です（手順は「使い方」のセクション）
  • 組織のセキュリティポリシーがある環境では導入できない場合があります
Release から入手

SmartScreen の警告について: Hodozip は未署名のため、インストーラーの実行時や初回起動時に Windows SmartScreen が「Windows によって PC が保護されました」という警告を表示することがあります。その場合は「詳細情報」を選び、「実行」をクリックすると起動できます。

インストーラー版と zip 版は、起動時に新しいバージョンを確認します（設定で OFF にできます）。MSIX 版は自動更新の対象外です。

使い方

1. インストールして起動する

インストーラー版（推奨）

  1. Hodozip-0.5.0-setup.exe をダウンロードして実行します。未署名のため、SmartScreen の警告が表示された場合は「詳細情報」→「実行」を選びます。
  2. インストール先は %LOCALAPPDATA%\Programs\Hodozip 固定です。「シェル統合」で右クリックメニューと「プログラムから開く」への登録を選べます（いずれも任意、既定で有効）。
  3. インストール後、スタートメニューの「Hodozip」から起動します。アンインストールは「設定」→「アプリ」→「インストールされているアプリ」から行えます。

zip 版（インストール不要）

  1. ダウンロードした zip ファイルを解凍します。
  2. 中の Hodozip.exe を起動します。
  3. アーカイブをウィンドウへドラッグ＆ドロップするか、「ファイルを選択」からアーカイブを選びます。解凍の進捗が表示され、完了後に「フォルダを開く」で解凍先を開けます。

MSIX 版（実験的配布）

「証明書 → パッケージ」の順でインストールします。詳しい手順とアンインストール方法は、README の「MSIX 版のインストール」を参照してください。

  1. 公開証明書 Hodozip-Test.cer をダウンロードします。
  2. 管理者権限の PowerShell で証明書を登録します。
certutil -addstore -f TrustedPeople .\Hodozip-Test.cer
  1. GitHub Releases から Hodozip-0.5.0.msix をダウンロードしてインストールします。
Add-AppxPackage -Path .\Hodozip-0.5.0.msix

ダブルクリックで解凍できるようにするには、次の「既定のアプリ」設定が必要です。

2. 対応アーカイブの既定のアプリに設定する（ダブルクリックで解凍）

Windows はファイルの関連付けをアプリ側から強制できません。次の手順で Hodozip を .zip などの対応拡張子の既定に設定してください。

  1. Windows の「設定」→「アプリ」→「既定のアプリ」を開きます。
  2. 検索欄に zip と入力して「.zip」を選びます。
  3. 一覧から「Hodozip」を選択します。

または、.zip を右クリック →「プログラムから開く」→「別のプログラムを選択」→「Hodozip」→「常にこのアプリを使って開く」を選びます。関連付けの候補には、インストーラー版または MSIX 版が登録されます。

3. 右クリックメニューから解凍する（MSIX 版 / Windows 11）

対応アーカイブを右クリックして、次のどちらかを選びます。

  • Hodozip で解凍 — アーカイブの内容に合わせて解凍先を自動判定します。
  • Hodozip でフォルダに解凍 — 必ずアーカイブ名のフォルダを作り、その中に展開します。

Windows 11 の新しい右クリックメニューに表示されない場合は、「その他のオプションを表示」（または Shift + F10）を選んでください。インストール直後はエクスプローラーを再起動すると反映されやすいです。このメニューは Windows 11 向けで、Windows 10 では表示されない場合があります。

4. アーカイブを圧縮する

次のいずれかの方法で圧縮を開始できます。

  • ドラッグ＆ドロップ — メイン画面にファイルやフォルダをドロップします。
  • 「ファイルを選択」 — メイン画面のボタンからファイルを選びます。
  • 右クリックメニュー — ファイルまたはフォルダを右クリックして「Hodozip で圧縮」を選びます（複数選択可）。

圧縮設定画面で、出力先とファイル名、形式（ZIP / 7z）、圧縮レベル（保存 / 標準 / 最高）、パスワード、ZIP のファイル名エンコーディング（UTF-8 / Shift_JIS）を指定します。ZIP のパスワードは AES で暗号化されます。7z のパスワードは SharpCompress の対応範囲外のため無視されます。出力ファイルが既にある場合は、既存の衝突ポリシーに従って連番または上書きになります。

作成できる形式は ZIP / 7z です。tar 系や RAR の作成には対応していません。

5. 自動アップデート（インストーラー版 / zip 版）

起動時に GitHub Releases の最新版を確認します。確認は最大 1 日 1 回で、失敗しても通常起動します。新版がある場合はメイン画面のバナーから「更新する」「後で」「このバージョンをスキップ」を選べます。

  • インストーラー版 — setup.exe をダウンロードし、SHA256 digest を照合してからインストーラーを起動します。
  • zip 版 — Release ページを開きます。ダウンロード後は手動で配置を置き換えてください。
  • MSIX 版 — 自動アップデートは無効です。Store または手動で更新してください。

設定画面の「起動時に更新を確認する」で ON / OFF を切り替えられます（既定 ON）。
